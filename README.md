# MAI LifeOS — Telegram-бот для студента

Telegram-бот с шестью основными модулями и отдельным защищённым модулем подарков: личный бюджет, учебный roadmap для Backend, расписание и дедлайны МАИ, вакансии/стажировки/фриланс, погода и автобус с396, RSS-новости и трекер часов кода.

## 1. Возможности

### 💰 Бюджет
- Добавление расходов с категориями.
- Статистика за календарный месяц и остаток от стартового бюджета 45 000 ₽.
- Подбор случайных рецептов под указанную сумму и кнопка обновления без повторения уже показанных вариантов, пока варианты в подборке не закончатся. Цены ориентировочные.
- Лимит доступа: первые 10 уникальных Telegram ID; остальные получают сообщение об отказе. Лимит хранится в SQLite и сохраняется после перезапуска.
- Данные сохраняются в SQLite.

### 📚 Путь в Backend
- Roadmap в заданном порядке: Python → алгоритмы и структуры данных → ООП и архитектура → Git и Linux → SQL и PostgreSQL → HTTP и REST → FastAPI/Django → тестирование → Docker → Redis/Celery → CI/CD → Linux server/Cloud → архитектура → production backend.
- Отметка тем как завершённых.
- Рекомендация следующей незакрытой темы.
- Задача дня по Python.
- Процент прохождения этапов Junior/Middle/Senior.
- Streak: в день должна быть отмечена завершённая тема или задача. Даты считаются по Москве.

Проценты Junior/Middle/Senior отображают прогресс чек-листа, а не гарантируют фактический уровень специалиста.

### 🎓 МАИ-хелпер
- Добавление пар вручную. Формат: `Пн 09:00 Математика; ауд. 312`.
- Дедлайны в формате `25.12.2026 Курсовая`.
- Обратный отсчёт до указанной даты сессии.

### 💼 Работа и фриланс
- Поиск вакансий Python без опыта через публичный API hh.ru (если API недоступен, бот показывает поисковую ссылку).
- Ссылки на Kwork и FL.ru.
- Поисковые ссылки на IT-стажировки.
- Шаблон резюме для начинающего.
- Идеи подработки и отдельный поиск по авиации/IT.

### 🌦 Погода и 🚌 отслеживание автобуса
- Погода по выбранному пользователем району.
- Персональные настройки маршрута: номер автобуса, остановка посадки и подпись направления. Настройки сохраняются в SQLite отдельно для каждого Telegram-пользователя.
- Попытка получить прогноз ближайших прибытий из табло «Московского Транспорта» через `https://moscowtransport.app/api/stop_v2/{stop_id}`. В ответе бот отдельно помечает прогнозы по телеметрии и прогнозы, основанные на расписании.
- Справочное расписание с396 в `bus_schedule.json` остаётся отдельным справочником только для маршрута Планерная → «Химико-технологический университет».

**Важно про live-режим:** у `moscowtransport.app/api/stop_v2` нет публичной гарантии стабильности API; это неофициальный, недокументированный endpoint, найденный в открытом проекте интеграции Home Assistant. Он может измениться, временно не работать или вернуть только расписание. Бот не называет расписание GPS-телеметрией и не выдумывает ETA при ошибке.

**Как настроить персональный автобус:** открой «Район и транспорт» → «Мой автобус — прогноз прибытия» (или «Настроить/изменить автобус»), введи номер маршрута, название остановки посадки и остановку для обозначения направления. Чтобы однозначно определить нужную платформу, дополнительно понадобится ссылка «Поделиться» на остановку из приложения «Московский транспорт» (короткая ссылка `https://moscowapp.mos.ru/l/...` тоже подойдёт). Одного названия недостаточно: у остановок с одинаковым названием могут быть разные платформы и направления. После сохранения нажимай «Обновить прогноз».

Источник идеи API и формат UUID остановки: https://github.com/egmen/moscow_transport. Официальный сервис «Московский Транспорт»: https://moscowtransport.app/.

### 🎁 Подарки за Telegram Stars (доступ по ID)
- В главном меню есть модуль «Подарок». Владелец `1844256493` имеет доступ всегда. Автоматически доступ также получают первые `MAX_USERS - 1` зарегистрированных пользователей, кроме владельца (9 пользователей при `MAX_USERS=10`); список рассчитывается по таблице `bot_access_users` в SQLite и сохраняется между перезапусками. Дополнительные ID можно вручную указать в `GIFT_ALLOWED_USER_IDS`.
- Бот запрашивает актуальный каталог доступных обычных подарков у Telegram и показывает только базовые подарки от 15 до 100 Stars, исключая premium-only подарки, исчерпанные лимитированные подарки и недоступные для этого бота варианты.
- Перед отправкой бот показывает баланс Stars, даёт выбрать подарок, запрашивает `@username`, проверяет настройки приёма подарков, показывает подтверждение и только после нажатия «Подтвердить отправку» вызывает `sendGift`.
- При недостаточном балансе бот сообщает цену подарка и текущий баланс. При запрете на получение соответствующего типа подарков выводится предупреждение.
- Telegram Bot API отправляет подарок по числовому `user_id`, а не по произвольному username. Поэтому бот сохраняет связь username → ID из updates Telegram. Получателю нужно хотя бы один раз написать этому боту после установки обновления; после этого можно выбрать его по username. Если он не зарегистрирован среди первых 10 пользователей, он может получить отказ в доступе к функциям, но его username будет записан перед отказом, чтобы владелец мог разрешить отправку подарка.
- Автоматически разрешённые ID не нужно вписывать в `.env`: бот сам выбирает первые девять зарегистрированных не-владельцев из SQLite (при `MAX_USERS=10`). Чтобы дополнительно разрешить конкретные ID вручную, можно задать `GIFT_ALLOWED_USER_IDS=123456789,987654321`. Владелец `GIFT_OWNER_ID` имеет доступ автоматически. Для применения ручных изменений `.env` перезапусти бота.
- Bot API может не раскрыть предварительные настройки приёма для старой версии aiogram или недоступного чата; тогда выполняется попытка отправки, а отказ Telegram обрабатывается как ошибка. Отправка подарка необратима через этот модуль; не подтверждай, если получатель или цена указаны неверно.

### 📰 Backend-новости и ⏱ часы кода
- Заголовки из публичных RSS-лент Habr; каждый заголовок содержит ссылку на источник.
- Трекер суммирует добавленные часы за сегодня, неделю и всё время.

## 2. Запуск на Windows

Нужен Python 3.11 или новее.

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Открой терминал в папке проекта и создай виртуальное окружение:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. Установи или обнови зависимости (новый модуль подарков использует свежие методы Telegram Bot API):

   ```powershell
   python -m pip install --upgrade -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env` и вставь токен:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ```

5. Запусти:

   ```powershell
   python bot.py
   ```

Для Linux/macOS активация окружения обычно выглядит как `source .venv/bin/activate`.

### Если появляется `ZoneInfoNotFoundError: Europe/Moscow`

Обнови зависимости в терминале PyCharm: `python -m pip install -r requirements.txt`. В зависимостях предусмотрен пакет `tzdata`; в `config.py` также есть резервная временная зона MSK (UTC+3) для Windows без базы IANA.

## 3. Где хранятся данные

По умолчанию база создаётся рядом с файлом запуска и называется `mai_lifeos.sqlite3`. Она содержит расходы, отметки roadmap, расписание, дедлайны, дату сессии и часы кодинга. Не отправляй файл базы или `.env` в публичный репозиторий, если не хочешь раскрывать свои данные.

Можно поменять путь и размер бюджета через `.env`:

```env
DATABASE_PATH=mai_lifeos.sqlite3
MONTHLY_BUDGET_DEFAULT=45000
HH_USER_AGENT=MAI-LifeOS-Bot/1.0 (your-email@example.com)
MAX_USERS=10
GIFT_OWNER_ID=1844256493
# Автоматический доступ первым 9 зарегистрированным пользователям не-владельцам
# выдаётся из SQLite; здесь можно указать только дополнительные ID вручную.
GIFT_ALLOWED_USER_IDS=
```

## 4. Справочное расписание автобуса

`bus_schedule.json` содержит пары времени отправления и прибытия в одинаковом порядке: `departures[i]` соответствует `arrivals[i]`. Это справочное расписание только для указанного направления с396, а не live GPS. При изменении расписания редактируй оба списка, сохраняя одинаковое количество элементов. `yandex_live_url` — ссылка для проверки фактического движения.

## 5. Перед публикацией на сервере

- Не храни токен внутри исходного кода.
- Используй отдельный Telegram-аккаунт для теста.
- Делай резервные копии SQLite.
- Для многопользовательского публичного запуска добавь лимиты запросов, логирование, обработку ошибок и тесты.
- При переходе к более серьёзному проекту вынеси логику в модули и добавь PostgreSQL, тесты, Docker и CI/CD по мере изучения.


### Совместимость с Python 3.13+

Модуль новостей разбирает RSS/Atom через встроенный `xml.etree.ElementTree`, поэтому отдельный `feedparser` не нужен и ошибка `No module named 'cgi'` от старой версии этой библиотеки не возникает.


## 6. Ограничение доступа

По умолчанию бот даёт доступ максимум 10 уникальным Telegram ID. Первые пользователи регистрируются автоматически при первом сообщении или нажатии кнопки; новые ID после заполнения лимита получают отказ. Доступ сохранится после перезапуска, потому что список хранится в таблице `bot_access_users` SQLite. Лимит можно изменить параметром `MAX_USERS` в `.env` до заполнения доступа. Если в старой базе уже были пользователи, при первом запуске миграции доступ сохраняется максимум для первых 10 существующих учётных записей.


## Оплата через Telegram Stars

В главном меню есть пункт «⭐ Поддержать проект». Пользователь может купить цифровой статус Supporter за 15, 25, 50, 100, 250 или 500 Stars. Оплата реализована стандартным Telegram Bot Payments API с валютой `XTR`. После успешного платежа бот сохраняет `telegram_payment_charge_id`, активирует статус в SQLite и уведомляет пользователя.

Перед выставлением счёта бот просит подтвердить условия. Есть команды `/terms` и `/paysupport`. Проверка до оплаты валидирует владельца счёта, payload, валюту и точную сумму; после оплаты повторная обработка того же заказа не выдаёт статус повторно.

Пользователь оплачивает счёт из своего доступного баланса Telegram Stars. Сами Stars можно приобрести доступными для пользователя способами Telegram: встроенная покупка в приложениях, `@PremiumBot` на поддерживаемых клиентах, а также Fragment в доступных сценариях. Доступность зависит от платформы, региона и аккаунта.

Важно: это не прямой перевод Stars с пользовательского баланса в баланс бота. Бот принимает платёж за цифровой статус Supporter; статус является цифровым результатом покупки внутри бота. Перед публичным использованием проверь условия Telegram для цифровых товаров, актуальную версию Bot API и сценарий возврата платежей.
