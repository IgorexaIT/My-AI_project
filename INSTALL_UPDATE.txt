MAI LifeOS — обновление отслеживания автобусов

Как установить:
1. Останови бота в PyCharm.
2. Сделай резервную копию папки проекта.
3. Распакуй содержимое архива прямо в папку проекта mai_lifeos_bot и согласись заменить bot.py, database.py, keyboards.py и README.md.
4. Новый файл bus_tracker.py должен лежать рядом с bot.py.
5. Не удаляй и не заменяй свои .env, mai_lifeos.sqlite3, .venv и папку .git.
6. Запусти бота снова. Таблица настроек автобусов создастся автоматически в SQLite.
7. Открой «Район и транспорт» → «Мой автобус — прогноз прибытия» и пройди настройку.

Для live-прогноза нужен URL конкретной остановки из приложения «Московский Транспорт»:
открой остановку → «Поделиться» → отправь ссылку боту. Если вводишь только название остановки, бот попросит ссылку отдельно.

Важное ограничение:
Подключение использует неофициальный недокументированный endpoint moscowtransport.app. В текущей среде не удалось проверить его живой ответ из-за недоступности DNS/сети, поэтому фактическую доступность нужно подтвердить первым запросом после установки. Бот явно различает прогнозы по телеметрии и по расписанию и не должен выдавать расписание за GPS. Для маршрута с396 сохранена отдельная кнопка справочного расписания.
